# Sistema de Férias — frontend

Aplicação Next.js (App Router) do sistema de férias. Instalação, variáveis de ambiente, execução e limitações estão no [README da raiz](../README.md).

```bash
npm ci
npm run dev    # http://localhost:3000, com a API em execução
npm run lint
npx tsc --noEmit
npm run build
```
